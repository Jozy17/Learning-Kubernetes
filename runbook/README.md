# VMware → Harvester migration runbook (placeholder)

This will become a generic, reusable runbook template covering:
- discovery/inventory: OS, disks, NICs, snapshots, VMware Tools, dependencies
- network and storage mapping
- pre-flight checklist
- sizing the import scratch storage
- cutover, validation and rollback

It'll be written alongside curriculum modules 05 (VMware concepts) and 06 (vm-import-controller),
so that every step can reference material you've already practised in the Tier 4 labs.

It will contain **no real hostnames, IPs or credentials**, only placeholders.
